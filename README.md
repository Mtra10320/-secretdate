# SecretDate v2
Prototype mobile-first indépendant.
Fonctions : écran majeur 18+, profils, likes, favoris, filtres, mode discret local, édition du profil, messages et événements.
Prototype front-end uniquement. Une version production nécessite serveur, comptes, vérification d'âge côté serveur, modération, stockage sécurisé et messagerie temps réel.
