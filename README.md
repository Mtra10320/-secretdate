# SecretDate

Prototype mobile-first de plateforme de rencontres adultes.

## Démo
Interface front-end sans compte ni serveur.

## À prévoir pour une version production
- authentification
- vérification d'âge
- profils et photos privés
- messagerie temps réel
- géolocalisation avec consentement
- modération et signalement
- événements
- abonnement Premium
- base de données et API
